## Возможности

- **Добавление студентов** — ввод имени, среднего балла и номера зачётной книжки.
- **Импорт из CSV** — загрузка студентов из файла с проверкой данных.
- **Просмотр списка** — вывод информации о студентах.
- **Фильтрация** — отбор студентов по среднему баллу.
- **Преобразование данных** — обработка информации о студентах с помощью `Stream API` и `map()`.
- **Сортировка** — сортировка студентов по имени без учёта регистра.
- **Проверка данных** — контроль корректности введённых значений и поиск дубликатов номеров зачётных книжек.
- **Обработка исключений** — обработка ошибок ввода и чтения файлов.
- **Собственная коллекция** — реализация динамического массива `MyArrayList<T>`.

## Запуск проекта без IntelliJ IDEA

### 1. Скачать проект

Клонируйте репозиторий:

```bash
git clone https://github.com/ZaplatiteZaSitePJ/Java-Practice-1.git
cd REPOSITORY
```

### 2. Скомпилировать проект

Из корневой папки проекта выполните команду.

**Windows PowerShell:**

```powershell
$files = Get-ChildItem src -Recurse -Filter *.java |
    ForEach-Object { $_.FullName }

javac -encoding UTF-8 -d out $files
```

**Linux / macOS:**

```bash
javac -encoding UTF-8 -d out $(find src -name "*.java")
```

Команды компилируют Java-файлы и помещают скомпилированные классы в каталог `out`.

### 3. Запустить приложение

```bash
java -cp out Main
```

## Запуск в IntelliJ IDEA

1. Откройте проект в IntelliJ IDEA.
2. Убедитесь, что для проекта настроен JDK.
3. Найдите класс с методом `main()`.
4. Запустите его с помощью кнопки Run.

## Примечания

- Номера зачётных книжек должны быть уникальными.
- Средний балл должен соответствовать диапазону, заданному в программе.
- При импорте из CSV некорректные строки могут быть пропущены с выводом сообщения об ошибке.
- Пути к файлам желательно задавать относительно корневой папки проекта, чтобы приложение работало на разных компьютерах.
- Собственная коллекция `MyArrayList<T>` реализует интерфейс `Iterable<T>`, операции добавления, получения и удаления элементов, определение размера и увеличение внутреннего массива по мере необходимости.
